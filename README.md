# PyMax Hashes

Небольшой сервис на Go, который дополняет [PyMax](https://github.com/MaxApiTeam/PyMax) актуальными метаданными для разных версий MAX.

Для каждой версии хранятся номер сборки, схема подписи и SHA-256-хеши сертифика, DEX-файлов и нативных библиотек.

## API

Актуальные данные доступны без авторизации:

`GET https://hashes.pymax.org/versions.json`

Ответ - JSON-объект, где ключом служит версия MAX, а значением - её метаданные.

Исходный код сервера открыт, чтобы логику хранения и обновления данных можно было проверить.

## Документация

Исходники — в [docs](docs/index.md). Для локального просмотра нужны Node.js и npm:

```sh
npm install
npm run docs:dev
```

Сборка: `npm run docs:build`. Готовый сайт — в `docs/.vitepress/dist`.
