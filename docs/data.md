# Формат данных

Каждая версия содержит объект метаданных:

| Поле | Тип | Содержимое |
| --- | --- | --- |
| `build_number` | integer | Номер сборки |
| `signature_scheme` | string | Схема подписи APK |
| `certificate_count` | integer | Количество сертификатов |
| `certificate_sha256` | string[] | SHA-256-хеши сертификатов |
| `certificate_meta_sha256` | string | SHA-256 метаданных сертификатов |
| `dex_meta_sha256` | string | SHA-256 метаданных DEX-файлов |
| `so_meta_sha256_arm64_v8a` | string | SHA-256 метаданных нативных библиотек arm64-v8a |
| `so_meta_sha256` | object | SHA-256 метаданных нативных библиотек по архитектурам |

Объект `so_meta_sha256` содержит строковые поля `arm64-v8a`, `armeabi-v7a`, `x86` и `x86_64`.

Сервис хранит и возвращает переданные значения. Он не вычисляет хеши и не проверяет их соответствие APK.
Алгоритм формирования полей `*_meta_sha256` в коде сервера не определён.

В `/versions.json` объекты метаданных сгруппированы по версии MAX.
В `/versions/latest` тот же объект находится в поле `data`, а номер версии — в `version`.
