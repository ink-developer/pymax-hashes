# Самостоятельный запуск

Нужны Docker и Docker Compose. Команды выполняются из корня репозитория.

## Подготовка

```sh
cp .env.example .env
mkdir -p data
```

В `.env` замените `AUTH_KEY` своим ключом. Для Compose оставьте `HOST=0.0.0.0`.

Серверу нужен существующий файл `data/apk_fingerprints.json`.
Поместите туда каталог версий либо создайте пустой JSON-объект `{}`.
Каталог `data` должен быть доступен контейнеру на запись: по умолчанию используются UID/GID `1000:1000`.
При необходимости задайте `APP_UID` и `APP_GID` в `.env` перед сборкой.

## Запуск

```sh
docker compose up -d --build
curl http://localhost:8080/versions.json
```

Данные сохраняются в каталоге `data` на хосте. Добавить версию можно через [PUT-запрос](./api.md#добавление-или-обновление).

## Настройки

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `DATA_PATH` | `data/apk_fingerprints.json` | Путь к JSON-каталогу |
| `HOST` | `0.0.0.0` | Адрес сервера |
| `PORT` | `8080` | Порт сервера |
| `AUTH_KEY` | Обязательна | Ключ для PUT-запросов |
| `GLOBAL_CACHE_TIME` | `600` | Кеш `/versions.json`, секунды |
| `LATEST_CACHE_TIME` | `300` | Кеш `/versions/latest`, секунды |

При запуске Go-сервера напрямую файл `.env` должен существовать в рабочем каталоге.
В Docker-образе пустой `.env` уже создан, а Compose передаёт значения из `.env` хоста через окружение.
