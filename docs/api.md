# API

Базовый URL: `https://hashes.pymax.org`.

## Все версии

`GET /versions.json`

Возвращает JSON-объект: ключ — версия MAX, значение — [метаданные](./data.md).
Если версий нет, ответ — `{}`. Успешный статус: `200`.

```sh
curl https://hashes.pymax.org/versions.json
```

Параметр `since` оставляет версии **начиная с указанной, включительно**.
Формат — три числа через точку. Сравнение числовое: `1.10.0` новее `1.9.0`.

```sh
curl 'https://hashes.pymax.org/versions.json?since=1.0.0'
```

## Последняя версия

`GET /versions/latest`

Возвращает объект с полями `version` (строка) и `data` ([метаданные](./data.md)).
Выбирается наибольшая версия по номеру, независимо от времени её добавления.
Успешный статус: `200`. Если версий нет — `404` с ошибкой `no versions`.

```sh
curl https://hashes.pymax.org/versions/latest
```

## Добавление или обновление

`PUT /versions/{version}`

Тело запроса — объект [метаданных](./data.md). Запись для указанной версии заменяется целиком.
Заголовок `Authorization` должен содержать значение `AUTH_KEY` без префикса `Bearer`.
Успешный ответ: `204`, без тела.

Пример для собственного сервера: `version.json` содержит метаданные, `AUTH_KEY` — ваш ключ в окружении shell.

```sh
curl -X PUT http://localhost:8080/versions/1.0.0 \
  -H "Authorization: $AUTH_KEY" \
  -H 'Content-Type: application/json' \
  --data-binary @version.json
```

## Кеширование

Успешные GET-ответы содержат `Cache-Control: public, max-age=…`:

| Метод | Время по умолчанию |
| --- | --- |
| `/versions.json` | 600 секунд |
| `/versions/latest` | 300 секунд |

После обновления данных ранее закешированные ответы могут сохраняться до истечения этого времени.
Значения задаются в [настройках сервера](./self-hosting.md#настройки).

## Ошибки

Ошибки обработчиков API возвращаются как JSON:

```json
{"error": "invalid auth"}
```

| Статус | Причина |
| --- | --- |
| `400` | Некорректный `since` или тело PUT-запроса (`invalid body`) |
| `401` | Неверный ключ авторизации (`invalid auth`) |
| `404` | Нет версий для `/versions/latest` (`no versions`) |
| `500` | Ошибка чтения, обработки или сохранения данных (`internal error`) |

Неизвестные пути возвращают HTML-страницу `404`.
